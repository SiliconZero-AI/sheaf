# Security

Sheaf is a local app. It reads and writes files in folders you choose to open. Drafts are not uploaded.

The desktop build uses a broad filesystem scope because it is a folder-based editor. Treat it like any other local text editor: only open folders you trust.

## Reporting a vulnerability

Please use [GitHub Security Advisories](https://github.com/SiliconZero-AI/sheaf/security/advisories/new) instead of a public issue.

If you cannot use advisories, email the address on the GitHub profile of [Mika](https://github.com/SiliconZero-AI).
